§3Codex prompt

I already have chat_turn_with_actions(text) from Task 14. I also have g1.get_rgbd() (returns a dict
with a "rgb_jpeg" key holding the current camera frame as JPEG bytes, or None if unavailable), and
openai_api_util.describe_image(client, jpeg_bytes, question) which answers a question about one frame.

Write a new function chat_turn_with_vision(text) that:
1. Detects whether text is a vision question (e.g. contains "siehst du", "was siehst", "kamera",
   "beschreibe").
2. If so: calls g1.get_rgbd(), checks the frame is not None, calls
   openai_api_util.describe_image(client, frame["rgb_jpeg"], text), prints the answer, and speaks it
   with g1.say(answer, language="DE").
3. Otherwise, fall back to chat_turn_with_actions(text).

Handle a None frame from get_rgbd() by speaking a short German error message instead of crashing.
