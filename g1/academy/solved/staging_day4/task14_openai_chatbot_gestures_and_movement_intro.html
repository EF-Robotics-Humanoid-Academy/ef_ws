§1Knowledge — gestures and fixed-step movement

High-level gestures take no arguments: g1.face_wave(), g1.clap(), g1.high_wave(), g1.shake_hand(), g1.hug(), g1.left_kiss().

CommandCall
step forwardg1.loco_move(0.15, 0, 0, 1.0)
step backwardg1.loco_move(-0.15, 0, 0, 1.0)
step leftg1.loco_move(0, 0.15, 0, 1.0)
step rightg1.loco_move(0, -0.15, 0, 1.0)
turn leftg1.loco_move(0, 0, 0.5, 1.0)
turn rightg1.loco_move(0, 0, -0.5, 1.0)

Always announce first: call g1.say(...) with what you are about to do before calling the gesture/movement method.

Safety: call g1.walk_mode() once before any movement command, and only run movement commands in a clear space. These step sizes are small and fixed on purpose — do not make them bigger.

§2Codex prompt

I already have chat_turn_with_knowledge(text) from Task 13. I also have a G1 instance g1 with these
no-argument high-level gestures: g1.face_wave(), g1.clap(), g1.high_wave(), g1.shake_hand(), g1.hug(),
g1.left_kiss(); and g1.loco_move(vx, vy, vyaw, duration_s) for movement, where a "step" is 1.0s at
vx=+-0.15 (forward/back), vy=+-0.15 (left/right), and a "turn" is 1.0s at vyaw=+-0.5 (left/right).

Write a new function chat_turn_with_actions(text) that:
1. First classifies the user's message as a plain question, a gesture request, or a movement command.
2. If it is a gesture or movement request: first call g1.say(...) announcing what you are about to do
   (in German), THEN call the matching g1 method from the tables above.
3. Otherwise, fall back to chat_turn_with_knowledge(text) for a normal spoken answer.
