§1Knowledge — the mapping lifecycle (recap of Day 2)

CallDoes
g1.start_mapping(slam_type="indoor")starts building a map from the LiDAR
g1.stop_mapping(save_path=...)finishes and saves the map
g1.relocate()relocalizes against the saved map at the current/last-known pose

Drive the robot around between start_mapping and stop_mapping (e.g. g1.loco_move(0.15, 0, 0.4, duration_s=8)) so the LiDAR sees enough of the room.

§2Knowledge — named points (same helper as Day 2)

import json
from pathlib import Path

POINTS_PATH = "slam_points.json"

def add_point(g1, name, points_path=POINTS_PATH):
    path = Path(points_path)
    points = json.loads(path.read_text()) if path.exists() else {}
    points[name] = list(g1.get_slam_pose())
    path.write_text(json.dumps(points))
    return points[name]

def remove_point(name, points_path=POINTS_PATH):
    path = Path(points_path)
    points = json.loads(path.read_text()) if path.exists() else {}
    points.pop(name, None)
    path.write_text(json.dumps(points))

Walk to the object and call add_point(g1, "pickup"); walk to the delivery spot and call add_point(g1, "dropoff"). g1.navigate_to_point(name) reads these back.

§3Knowledge — reach, grip, and release

right_arm_forward_pose.json is a flat {joint_id: q} dict, ready for g1.interpolate_to_pose(pose) — load it with json.load, no need to call g1.save(...) first.

CallDoes
g1.interpolate_to_pose(pose)smoothly moves the arm/waist to the given pose (per-joint speed capped at DEFAULT_MAX_JOINT_SPEED_RAD_S = 0.6 rad/s, damping capped at MAX_KD = 10.0 — enforced by the wrapper, not something you set)
g1.open_dex3_hand() / g1.close_dex3_hand()opens/closes both Dex3 fingers
g1.navigate_to_point(name)navigates to a saved named point and blocks until arrival

Order: navigate_to_point("pickup") → open_dex3_hand() → interpolate_to_pose(pose) → close_dex3_hand() → navigate_to_point("dropoff") → open_dex3_hand().

Safety

Clear the space before mapping/driving and before any navigation call. Keep hands clear of the Dex3 hand while it opens/closes.
