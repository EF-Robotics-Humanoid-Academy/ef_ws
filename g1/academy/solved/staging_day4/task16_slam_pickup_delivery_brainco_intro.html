Task 16: BrainCo Revo 2 pickup and delivery

This is a copy of the pickup-and-delivery task for a BrainCo Revo 2 hand. It uses open_brainco_hand() and close_brainco_hand(), not the Dex3 helpers.

  1. Use a Python 3.9–3.12 kernel, install bc_stark_sdk, and confirm that auto-detection finds the intended hand at device_index=0.
  2. Keep fingers clear. The hand is opened before the arm reaches the object.
  3. Only close after vision confirms the object and the arm is in its grasp pose.
  4. At delivery, open the hand and release the arm.
