Text in (English or German), a reply from the OpenAI API, printed and spoken back through g1.say(). The foundation Tasks 13–15 extend.

Knowledge Task 12

Knowledge — chat_reply and history

CallDoes
openai_api_util.get_client()reads OPENAI_API_KEY from the environment automatically — already set on every account
openai_api_util.chat_reply(client, text, history=history)sends text plus the running history list to the model, returns its reply

history is a plain list of {"role": ..., "content": ...} dicts — append both sides after every turn and pass the same list back in, so the model keeps context. The default system prompt always answers in German, whatever language it is asked in.

Solution Task 12

Solution — chat_turn(text)

history = []

def chat_turn(text):
    reply = openai_api_util.chat_reply(client, text, history=history)
    history.append({"role": "user", "content": text})
    history.append({"role": "assistant", "content": reply})
    print(reply)
    g1.say(reply, language="DE")
    return reply
This task never moves the robot — only speech. Full reference: staging_day4/task12_openai_chatbot_basic.ipynb and its intro page.

Task 16 — SLAM Pickup and Delivery

Builds onDay 2's add_point/remove_point, Day 3's interpolate_to_pose.
Wrapper methodsstart_mapping, stop_mapping, relocate, navigate_to_point, open_dex3_hand, close_dex3_hand

The capstone: map a space, save two named points, then fetch an object from one and deliver it to the other.
