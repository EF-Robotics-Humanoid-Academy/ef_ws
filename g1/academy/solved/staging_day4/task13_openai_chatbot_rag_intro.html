§3Codex prompt

I already have chat_turn(text) from Task 12 (uses openai_api_util.chat_reply(client, text,
history=history) and speaks the reply with g1.say(reply, language="DE")).

I also have knowledge = openai_api_util.load_knowledge_base("g1_academy_knowledge_de.json"), a list of
{"question", "answer", "category"}, and openai_api_util.retrieve_relevant(knowledge, query, top_k=3),
which returns the most relevant entries.

Write a new function chat_turn_with_knowledge(text) that:
1. calls retrieve_relevant(knowledge, text, top_k=3) to find the 3 most relevant knowledge entries,
2. adds them as extra context (question+answer pairs) before the user's message,
3. otherwise behaves exactly like chat_turn: calls openai_api_util.chat_reply(...), updates history,
   prints the reply, and speaks it with g1.say(reply, language="DE").
