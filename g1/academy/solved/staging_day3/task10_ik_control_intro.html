§1Knowledge — the arm as a serial manipulator

Each arm is a 7-joint open kinematic chain from the shoulder to the palm. hand_pose_navigation.arm_fk.ArmFK computes T_base_hand from those 7 angles; arm_ik.ArmIK solves the inverse (target pose → joint angles) with damped least squares.

Joint (arm-local)Left limits (rad)Right limits (rad)
shoulder pitch-3.089 .. 2.670-2.670 .. 3.089
shoulder roll-1.571 .. 2.200-2.200 .. 1.571
shoulder yaw±2.182±2.182
elbow-1.047 .. 2.094-1.047 .. 2.094
wrist roll/pitch/yaw±1.972 / ±1.658 / ±1.658±1.972 / ±1.658 / ±1.658

Chain: base → shoulder (q1 pitch, q2 roll, q3 yaw) → elbow (q4) → wrist (q5 roll, q6 pitch, q7 yaw) → palm/EE. Joint indices 15–21 are the left arm, 22–28 the right arm (see Task 9's index table), in that same shoulder→wrist order.

§2Knowledge — increment, clamp, ramp — never jump

The solver returns a joint solution, not a trajectory — clip the delta to max_dq and step to it at a bounded Cartesian speed (max_speed), exactly like Task 8's ease-curve interpolation.

If q_sol is None (unreachable/no convergence), return {"success": False, "ik": info} and do not move — a failed solve must never fall through to a partial or garbage move.

Flow: read current upper-body pose → FK: current q → current T_base_hand → offset target by (dx, dy, dz) → IK solve → q_solution → clip |delta q| <= max_dq → ramp to target (eased steps @ rate_hz). ik_move_ee(hand, dx, dy, dz) is one call = one small step, not a teleport to the solved pose.

def current_upper_body_pose(timeout_s=3.0):
    deadline = time.time() + timeout_s
    while time.time() < deadline:
        msg = lowstate_sub.message
        if msg is not None:
            return {j: float(msg.motor_state[j].q) for j in UPPER_BODY_JOINTS}
        time.sleep(0.02)

import numpy as np
from hand_pose_navigation.arm_fk import ArmFK
from hand_pose_navigation.arm_ik import ArmIK

_fk_cache, _ik_cache = {}, {}

def fk_solver(side):
    if side not in _fk_cache:
        _fk_cache[side] = ArmFK(side, "urdf")
    return _fk_cache[side]

def ik_solver(side):
    if side not in _ik_cache:
        _ik_cache[side] = ArmIK(side, "dls", max_iter=24, tol_pos_m=0.005, tol_rot_rad=0.02)
    return _ik_cache[side]

def ik_move_ee(hand, dx=0.0, dy=0.0, dz=0.0, max_speed=0.25, max_dq=0.15, rate_hz=50.0):
    side = "right" if str(hand).lower().startswith("r") else "left"
    joints = RIGHT_ARM_JOINTS if side == "right" else LEFT_ARM_JOINTS
    current = current_upper_body_pose()
    q_init = np.array([current[j] for j in joints])
    fk = fk_solver(side)
    target_T = fk.compute_arm(q_init).copy()
    target_T[0, 3] += dx
    target_T[1, 3] += dy if side == "left" else -dy            # mirrored sign by side
    target_T[2, 3] += dz
    q_sol, info = ik_solver(side).solve(target_T, q_init=q_init)
    if q_sol is None:
        return {"success": False, "ik": info}                  # never move on a failed solve
    delta = np.clip(np.asarray(q_sol) - q_init, -max_dq, max_dq)
    target_q = q_init + delta
    target = dict(current)
    for i, j in enumerate(joints):
        target[j] = float(target_q[i])
    remaining = max(abs(target[j] - current[j]) for j in joints)
    steps = max(1, int(np.ceil(remaining / max(1e-4, max_speed / rate_hz))))
    for step in range(1, steps + 1):
        smooth = _ease(step / steps)                            # same ease curve as Task 8
        frame = {j: current[j] + (target[j]-current[j])*smooth for j in joints}
        write_arm_sdk_pose({**current, **frame})
        time.sleep(1.0 / rate_hz)
    return {"success": True, "ik": info, "steps": steps}

def _ease(ratio):
    return ratio * ratio * (3 - 2 * ratio)

def current_palm_xyz(hand="right"):
    side = "right" if str(hand).lower().startswith("r") else "left"
    joints = RIGHT_ARM_JOINTS if side == "right" else LEFT_ARM_JOINTS
    current = current_upper_body_pose()
    q = np.array([current[j] for j in joints])
    return tuple(float(v) for v in fk_solver(side).compute_arm(q)[:3, 3])
