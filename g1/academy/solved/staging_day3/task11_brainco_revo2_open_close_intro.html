Task 11: BrainCo Revo 2 open and close

This is the BrainCo version of the Dex3 hand task. It does not use Unitree Dex3 DDS topics.

  1. Use a Python 3.9–3.12 kernel and install bc_stark_sdk in that environment. For serial connections, add the user to dialout and log in again.
  2. Connect the intended hand and make sure fingers and objects are clear.
  3. Run the notebook. The wrapper detects BrainCo devices automatically; device_index=0 selects the first one.
  4. Observe open, close, then the final open command.

The BrainCo normalized position range is 0–1000: zero opens all six fingers and 1000 closes them. Do not run a close command until the hand is clear.
