Introduction

This task is your first hands-on pass at the G1's low-level arm control path: move_ll_joint, and the two functions that safely hand control between your commands and Unitree's built-in AI Sport controller: release_arms() / engage_arms(). It closes with the basics of the Dex3 dexterous hand: opening, closing, releasing the fingers, and reading tactile pressure.

Every low-level command below rides on the rt/arm_sdk topic. rt/arm_sdk does not take exclusive ownership of the arms the way full rt/lowcmd dev-mode does -- it *blends* with AI Sport using a weight value in [0, 1]: weight=1 means your command fully drives the joint, weight=0 hands it back to AI Sport. release_arms()/engage_arms() ramp that weight smoothly instead of snapping it, which is why you always call one of them before/after a block of direct joint commands.

Before you touch anything: read every markdown cell in a section before writing its code -- each one calls out exactly which safety limits apply.

Setup

Connect to the robot over DDS and get a G1 handle. Everything else in this notebook is a method on that handle.

  • G1(iface, domain_id=0) -- opens the DDS channel factory on network interface iface (this classroom rig uses "eth0") and initializes the locomotion/FSM client used elsewhere. Construct exactly one G1 per kernel.
  • from sdk_wrapper import * also pulls in the joint-index constants (WAIST_JOINTS, LEFT_ARM_JOINTS, RIGHT_ARM_JOINTS, ...) you'll use to pick a joint below.

Task 1 - Pick a joint and read its live state: get_lowstate()

Joint indices on this rig: 0-11 legs, 12-14 waist, 15-21 left arm, 22-28 right arm (right shoulder roll is 23). g1.get_lowstate() returns a dict with joint_positions, joint_velocities, joint_torques (one float per joint index) and an imu reading -- read the current position of a joint before you command a delta from it, don't guess an absolute angle.

Task 2 - Command one joint: move_ll_joint(joint_id, q, dq=0.0, kp=40.0, kd=1.0, tau=0.0, dev_mode=False, ...)

Commands a single joint while holding every other upper-body joint at its currently observed position, then ramps smoothly to q on its own (no manual loop needed). q/dq/kp/kd/tau are a virtual spring-damper: kp pulls toward the target position, kd damps velocity, tau is a feed-forward torque added on top. The default (dev_mode=False) path uses rt/arm_sdk and only accepts waist/arm joints (12-28) while AI Sport stays the nominal owner.

Safety: kd (damping) is hard-clamped to MAX_KD = 10.0 inside the publisher no matter what you pass -- treat 10 as a *ceiling*, not a target. Start much lower (kd ~= 1-3) and only raise it if the joint feels underdamped/oscillatory. kp (stiffness) is not clamped -- a large kp on a joint far from its current position moves it fast and hard, so always read q first (Task 1) and command a small delta from it (the example below moves +/-0.2 to 0.5 rad from the live position, never an arbitrary absolute angle).

Task 3 - Hand control back: release_arms(duration_s=3.0, rate_hz=50.0)

Eases the rt/arm_sdk blend weight from 1 -> 0 over duration_s, so AI Sport smoothly regains control instead of the arm snapping stiff-to-loose. Call this before letting go of the arm physically, before stepping away, and before any teach-by-hand session.

Task 4 - Command again, then re-engage: move_ll_joint(...) + engage_arms(duration_s=1.0, rate_hz=50.0)

Calling move_ll_joint directly writes a full-weight (1.0) rt/arm_sdk frame immediately -- unlike release_arms(), it does not ease the weight back up. Below you'll do both: first a direct move_ll_joint call (an instant handoff back to your command), then engage_arms() itself (a smooth 0 -> 1 ramp) before one more move. In your own code, prefer calling engage_arms() first when you can.

Task 5 - Dex3 hand basics: open / close / release / tactile pressure

  • open_dex3_hand(hand="both", hold_s=0.6, rate_hz=50.0, ramp_s=None) / close_dex3_hand(...) -- ramp to preset open/closed finger targets using gentle gains (kp=1.5, kd=0.1, tau=0.03; fingers are light and don't need arm-scale stiffness).
  • release_fingers(hand="right", hold_s=0.5, rate_hz=50.0, persistent=True) -- makes the fingers backdrivable (near-zero gain) at their last commanded pose. persistent=True (the default) keeps doing this on a background thread until you call stop_release_fingers().
  • get_dex3_tactile_pressures(hand="both") -- returns per-sensor pressure floats you can use to sense contact/grasp force.

Safety: always open_dex3_hand before close_dex3_hand on an unfamiliar object -- closing onto something already in the palm without a known pressure baseline can over-grip it.
