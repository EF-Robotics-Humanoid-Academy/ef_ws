§1Knowledge — two arm control paths, never both at once

G1ArmActionClient.ExecuteAction(action_id) triggers a documented, firmware-baked gesture. It must never run concurrently with a low-level rt/arm_sdk command stream — finish or release one before starting the other.

GestureAction id
release arm99
clap17
face wave25
high wave26
shake hand27 (2s auto-release)
hug19 (2s auto-release)

Pick one lane at a time: G1ArmActionClient.ExecuteAction(id) OR ramp rt/arm_sdk weight 0→1 to own the arm, then ramp 1→0 (release_arms) — this course's controller-ownership rule, restated for the arm.

§2Knowledge — the arm_sdk weight byte and gains

Every low-level write below fills a complete LowCmd_ frame, including motor_cmd[29].q — not a real joint, but the weight that arbitrates between the default controller and this publisher.

motor_cmd[29].qMeaning
0.0released — default controller owns the arm/waist joints
1.0this publisher fully owns the arm/waist joints
0 < w < 1mid-handoff — only valid while release_arms/engage_arms is actively ramping

release_arms/engage_arms ramp that weight on an ease curve (3t²-2t³, not linear) from 1→0 or 0→1 — run release_arms() before this publisher stops owning rt/arm_sdk.

Waist joints (12–14) get higher default gains (kp=480, kd=12) than the arm joints (kp=30, kd=1.5) — the waist needs to hold torso posture against gravity, the arm can be softer.

def exec_arm_action(name, release_after_s=None):
    code = int(arm_action_client.ExecuteAction(HL_ARM_ACTIONS[name]))
    if release_after_s is not None:
        time.sleep(release_after_s)
        release = int(arm_action_client.ExecuteAction(HL_ARM_ACTIONS["release arm"]))

    return code

def current_upper_body_pose(timeout_s=3.0):
    deadline = time.time() + timeout_s
    while time.time() < deadline:
        msg = lowstate_sub.message
        if msg is not None:
            return {j: float(msg.motor_state[j].q) for j in UPPER_BODY_JOINTS}
        time.sleep(0.02)
    raise TimeoutError("Timed out waiting for rt/lowstate")

_crc = CRC()
arm_sdk_pub = ChannelPublisher("rt/arm_sdk", LowCmd_); arm_sdk_pub.Init()

def write_arm_sdk_pose(targets, weight=1.0, kp=30.0, kd=1.5, waist_kp=480.0, waist_kd=12.0):
    msg = unitree_hg_msg_dds__LowCmd_(); msg.mode_pr = 0; msg.mode_machine = 0
    msg.motor_cmd[29].q = max(0.0, min(1.0, weight))          # the arm_sdk enable/weight byte, not a joint
    for joint, q in targets.items():
        cmd = msg.motor_cmd[int(joint)]
        cmd.mode = 1; cmd.q = float(q); cmd.dq = 0.0; cmd.tau = 0.0
        cmd.kp = waist_kp if int(joint) in WAIST_JOINTS else kp
        cmd.kd = waist_kd if int(joint) in WAIST_JOINTS else kd
    msg.crc = _crc.Crc(msg)
    arm_sdk_pub.Write(msg)

Ramp the arm_sdk weight smoothly (an ease curve, not a step) from 1→0 to hand control back to the default controller, or 0→1 to take it — every low-level helper below must run this before/after it owns rt/arm_sdk.

def _ease(ratio):
    return ratio * ratio * (3 - 2 * ratio)                    # smoothstep, not linear

def release_arms(steps=150, rate_hz=50.0):
    pose = current_upper_body_pose()
    for i in range(steps + 1):
        weight = 1.0 - _ease(i / steps)
        write_arm_sdk_pose(pose, weight=weight, kp=30.0*weight, kd=1.5*weight,
                            waist_kp=480.0*weight, waist_kd=12.0*weight)
        time.sleep(1.0 / rate_hz)
    return {"final_weight": 0.0}

def engage_arms(steps=50, rate_hz=50.0):
    pose = current_upper_body_pose()
    for i in range(steps + 1):
        weight = i / steps                                    # no ease needed on the way in
        write_arm_sdk_pose(pose, weight=weight)
        time.sleep(1.0 / rate_hz)
    return {"final_weight": 1.0}

Capture the current pose under a name (persisted to JSON so it survives a kernel restart), and smoothly interpolate from wherever the arm currently is to a saved (or literal) pose using the same ease curve.

_ll_pose_path = Path("ll_poses.json")

def _load_ll_poses():
    return json.loads(_ll_pose_path.read_text()) if _ll_pose_path.exists() else {}

def save_current_ll_pose(name):
    pose = current_upper_body_pose()
    poses = _load_ll_poses()
    poses[str(name)] = pose
    _ll_pose_path.write_text(json.dumps(poses, indent=2))
    return pose

def interpolate_to_ll_pose(name_or_pose, duration_s=4.0, steps=150):
    if isinstance(name_or_pose, str):
        target = {int(j): float(q) for j, q in _load_ll_poses()[name_or_pose].items()}
    else:
        target = {int(j): float(q) for j, q in name_or_pose.items()}
    start = current_upper_body_pose()
    for step in range(1, steps + 1):
        smooth = _ease(step / steps)
        frame = {j: start.get(j, q) + (q - start.get(j, q)) * smooth for j, q in target.items()}
        write_arm_sdk_pose(frame)
        time.sleep(duration_s / steps)
    return {"target": target, "steps": steps}

teach appends the current pose as the next waypoint of a named, persisted sequence — call it repeatedly (physically moving the arm, e.g. after damp_mode(), between calls) to build up a multi-waypoint motion. repeat plays every waypoint back in order via interpolate_to_ll_pose, so playback is exactly as smooth as any other low-level move here.

_sequence_path = Path("arm_sequences.json")

def _load_sequences():
    return json.loads(_sequence_path.read_text()) if _sequence_path.exists() else {}

def teach(sequence_name, reset=False):
    sequences = _load_sequences()
    if reset or sequence_name not in sequences:
        sequences[sequence_name] = []
    sequences[sequence_name].append(current_upper_body_pose())
    _sequence_path.write_text(json.dumps(sequences, indent=2))
    return len(sequences[sequence_name])

def repeat(sequence_name, waypoint_duration_s=3.0, steps_per_waypoint=100):
    waypoints = _load_sequences()[sequence_name]
    for waypoint in waypoints:
        interpolate_to_ll_pose(waypoint, duration_s=waypoint_duration_s, steps=steps_per_waypoint)
    return {"sequence": sequence_name, "waypoints": len(waypoints)}
