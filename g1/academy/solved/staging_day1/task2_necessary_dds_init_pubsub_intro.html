§1Knowledge — ChannelFactory is global process state

ChannelFactoryInitialize(domain_id, interface) sets up the DDS participant for the whole process (kernel) — not per-object, per-topic, or per-notebook-cell.

  • Call it exactly once, before constructing any ChannelSubscriber/ChannelPublisher.
  • Always the same (domain_id, interface) for the life of that process — a second call with different settings must not silently reconnect (that would leave half your subscribers on the old settings).
  • In Jupyter, "restart the kernel" is your reset button when you need a different interface/domain — not a workaround, the intended way.

Setup order: factory once → ChannelPublisher/ChannelSubscriber(topic, type) → .Init(callback, queue_len) / .Init().

§2Knowledge — subscriber callbacks are asynchronous

A ChannelSubscriber callback runs on a background thread whenever a message arrives. Between messages, whatever you cached last time is all you have — it can be None (nothing received yet) or stale (publisher died, wrong topic, wrong domain/interface).

The fix is one small class: cache the newest message + its time.time() receipt time, and expose a fresh(max_age_s) check so every later call site can refuse stale data in one line instead of repeating the staleness math.

Module-level guard: initialize once, store the config, raise on a conflicting re-call, return the stored config either way.

_factory_config = None

def ensure_channel_factory(domain_id, interface):
    global _factory_config
    config = (int(domain_id), str(interface))
    if _factory_config is None:
        ChannelFactoryInitialize(*config)
        _factory_config = config
    elif _factory_config != config:
        raise RuntimeError(f"ChannelFactory already initialized as {_factory_config}; restart kernel for {config}.")
    return _factory_config

ensure_channel_factory(0, "eth0")

Constructor takes (topic, message_type, queue_len=10); the callback stores self.message/self.timestamp; fresh(max_age_s=0.5) returns whether the cached message exists and is recent enough.

class Latest:
    def __init__(self, topic, message_type, queue_len=10):
        self.message = None
        self.timestamp = 0.0
        self.subscriber = ChannelSubscriber(topic, message_type)
        self.subscriber.Init(self._callback, queue_len)

    def _callback(self, message):
        self.message = message
        self.timestamp = time.time()

    def fresh(self, max_age_s=0.5):
        return self.message is not None and time.time() - self.timestamp <= max_age_s

lowstate_sub = Latest("rt/lowstate", LowState_)

Hint: subscribing to rt/lowstate first is deliberate — it is the topic every later task also needs, so you can immediately tell whether your guard + cache actually work.

def make_publisher(topic, message_type):
    publisher = ChannelPublisher(topic, message_type)
    publisher.Init()
    return publisher

def diagnose(latest, name, max_age_s=0.5):
    if latest.message is None:
        return f"{name}: no message received yet (publisher not running / topic name wrong / domain-id or interface mismatch)"
    age = time.time() - latest.timestamp
    return f"{name}: last message {age:.2f}s ago" + (" (stale)" if age > max_age_s else " (fresh)")

print(diagnose(lowstate_sub, "lowstate"))
