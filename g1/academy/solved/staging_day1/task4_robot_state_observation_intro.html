Task 4: Create a safe custom mode with Codex

Create custom_mode.py using the local sdk_wrapper.py.

  1. Ask Codex for exactly one G1(iface="eth0", domain_id=0) instance and an enter_custom_mode() function.
  2. The function must call g1.say("entering custom mode"), then g1.set_headlight("blue", intensity=60, duration_s=5), and print a status.
  3. Before running it, check that the script has no locomotion, arm, mode-switching, or developer-mode calls.
  4. Run python custom_mode.py. It should only announce the message and turn the headlight blue for about five seconds.
