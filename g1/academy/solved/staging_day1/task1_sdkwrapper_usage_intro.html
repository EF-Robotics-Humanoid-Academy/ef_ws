§1What you already have

sdk_wrapper.py's G1 class is the finished, working wrapper this entire course reconstructs one native piece at a time. G1.__init__ already calls the module-level _ensure_factory guard for you, so you do not need your own ChannelFactoryInitialize guard when working through sdk_wrapper — that guard is exactly what you build from scratch in Task 2.

One instance per kernel

G1.__init__ still only tolerates one (domain_id, iface) pair per process (it calls _ensure_factory(domain_id, iface) once). Construct exactly one G1 per kernel, and restart the kernel before pointing it at a different interface or domain — a second construction with different settings raises RuntimeError.

What to write instead of g1 = None:

That single line is doing a lot underneath — it initializes the DDS factory, constructs a LocoClient, and lazily wires up every subscriber the class will need (lowstate, odometry, SLAM, battery, audio, ...). None of the request/response clients (audio, arm action, video, SLAM, robot-state, motion-switcher) are constructed yet — they are built lazily the first time a method that needs them is called (see _audio_client(), _arm_action_client(), etc. in sdk_wrapper.py).

§3Cell 5 — g1.say(text, language="EN", volume=100)

What it does underneath

say synthesizes text with Piper (a local TTS engine), converts the resulting WAV to mono / 16-bit / 16 kHz PCM, and streams it through AudioClient.PlayStream. language accepts the short codes documented in sdk_wrapper._PIPER_VOICES (en, de, fr, es, ar, plus a few long-form aliases like "english"). It raises ValueError for an unsupported language and FileNotFoundError if the matching Piper voice model is not installed.

§4Cell 7 — g1.set_headlight(color="green", intensity=100, duration_s=3)

What it does underneath

color accepts a name ("green"), a #RRGGBB hex string, or an "R,G,B" string; intensity (0–100) scales brightness before the color is sent. If duration_s > 0, G1 starts a background thread that keeps refreshing AudioClient.LedControl with that color every 0.2s until the duration elapses; a new call to set_headlight cancels and joins any thread still running from a previous call before starting its own, so repeated calls are last-call-wins. duration_s <= 0 sends a single LedControl call and returns immediately (no thread).

§5Where this goes from here

g1 exposes far more than these two calls: get_state/get_lowstate/ get_odom/get_battery/get_slam_info/get_service, damp_mode/prepare_mode/walk_mode/run_mode, toggle_service/toggle_gait, release_arms/engage_arms, loco_move/loco_stop, move_ll_joint, open_dex3_hand/close_dex3_hand, start_mapping/stop_mapping/ relocate/navigate, clap/face_wave/shake_hand, and ik_move_ee/extend_arm. Tasks 2–13 rebuild each of these pieces natively, one lesson at a time, until you could have written sdk_wrapper.py yourself. Task 2 starts with the very first piece: the DDS init guard G1.__init__ already did for you here.

Safety
