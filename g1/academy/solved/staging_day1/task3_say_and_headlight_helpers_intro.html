Task 3: Create an empty dashboard with Codex

Build the visual layout only. The dashboard must not control the robot yet.

  1. Open a Jupyter terminal in ~/academy/day_1.
  2. Ask Codex to create robot_dashboard.py with a title G1 Control Dashboard and large placeholder buttons: Speak, Headlight, Prepare, Walk, and Stop.
  3. Tell Codex: no callbacks, no G1 import or construction, and no robot commands. Use host 0.0.0.0 and port 8060.
  4. Read the generated file, then run python robot_dashboard.py and open the printed URL.

Success means the buttons appear and clicking them does nothing.
