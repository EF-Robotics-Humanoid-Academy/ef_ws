G1 Academy — Day 1

Today is about using supplied examples and asking Codex for small, safe programs. Follow each task notebook in order.

Task 1

Complete the existing SDK-wrapper introduction notebook.

Task 2 — Run an audio example

Open File → New → Terminal in Jupyter, then run:

cd /home/unitree/unitree_sdk2_python/example/g1/audio
python g1_audio_client_example.py eth0

Listen for the example audio and record your result in the notebook.

Task 3 — Empty dashboard

Ask Codex for a Dash layout with placeholder Speak, Headlight, Prepare, Walk, and Stop buttons. It must contain no G1 object, callback, or robot command. Start it on port 8060 and check that the buttons appear.

Task 4 — Custom audio-and-light mode

Ask Codex for a custom_mode.py script that uses the local sdk_wrapper.py to announce "entering custom mode" and set a blue headlight for five seconds. Do not add locomotion, arms, mode switching, or developer mode.

Before running anything

Read the generated file first. Confirm the robot has clear space and a supervisor is aware. Task 4 is limited to audio and light only.
